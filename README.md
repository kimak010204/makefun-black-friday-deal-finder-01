Black Friday Deal Radar is a fast, static deal finder holding 44 real Black Friday 2026 deals from 7 stores — Amazon, Best Buy, Walmart, Target, Newegg, B&H Photo and Home Depot — each with its sale price, usual price, discount, store link, check time and source, plus an honest verdict (new low, strong deal, routine sale or weak deal) with one line of evidence. It searches by product, store or category, filters by category, store and minimum discount, sorts by new lows first, biggest discount, biggest saving or lowest price, and opens a detail page for every deal with a cross-store price comparison where the same product was found elsewhere.

## Run it

```sh
node serve.ts
```
